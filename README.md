# ED Visit Explorer

The finished app from the tutorial "From Python to URL" (BMI 640, Lecture 2): a small
Streamlit app for exploring a synthetic emergency department dataset.

- `From_Python_to_URL.pdf`: step-by-step written instructions that follow the video
- `app.py`: the finished app
- `requirements.txt`: the packages the app needs
- `data/ed_visits.csv`: 2,000 synthetic ED visits (generated data, no real patients)

To run it locally: create and activate a virtual environment, run
`pip install -r requirements.txt`, then `streamlit run app.py`.
